Matrixmul python program

The matrixmul program accepts two inputs:
	- the number of processes (Enter number of processes: )
	- input file type (Select input type rand or file: ) Optional 
It generates resultant matrix Output.txt file in the provided output file path.

Input and Output path needs to be set in the program (using input_filepath and output_filepath respectively).
